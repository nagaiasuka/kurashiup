# 記事コンテンツのGit管理

記事本文・比較データ・アフィリエイトリンク・商品画像・アイキャッチ・生成スクリプトを、このディレクトリで管理する。

`review-guides/<記事スラッグ>/` を記事ごとの保存先とする。更新は生成元に反映し、生成物の表示とリンクを確認してからコミット・プッシュする。

現在の `.github/workflows/deploy.yml` が配信するのは `wp-content/themes/kurashiup-theme/` のみ。`content/` の追加・マージではWordPressの投稿やメディアは更新されない。記事の公開には、WordPressへの画像アップロード、記事登録、アイキャッチ設定、公開画面の確認が別途必要。

公開した記事は、各記事の `公開準備.json` に公開URL・投稿ID・アイキャッチのメディアIDと確認結果を記録する。未公開のものを公開済みとして記録しない。認証情報はGitに保存しない。
